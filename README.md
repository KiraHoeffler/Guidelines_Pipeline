# Guidelines_Pipeline

Here, we provide an example MWAS pipeline from raw IDAT files to a case-control analysis. 

Please download the Resources folder here: 
https://universityofbergen-my.sharepoint.com/:f:/g/personal/kira_hoeffler_uib_no/IgDy_tQ8RcM2SIRQi6KqKwisAbLa_75LqX5Kmpj2Zn37WKY?e=NCZgvq

Please read the Guide carefully before you start using this pipeline. 
The case-control scripts in the script folder need to be adapted manually if a different phenotype than "case-control" is used. If only a subset of the QCed data is used, please add a filtering step in the case-control scripts and run an additional PCA on the filtered M values to check for outliers.
